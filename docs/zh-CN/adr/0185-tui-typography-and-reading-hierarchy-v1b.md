# ADR 0185：TUI 排版与阅读层级 V1B

**简体中文** · [English](../../en/adr/0185-tui-typography-and-reading-hierarchy-v1b.md)

- 状态：已接受
- 日期：2026-09-30

## 背景

V1A 已确立颜色与表面契约，但表现层仍把整段用户消息和错误消息、几乎所有
Markdown 标题与列表标记、工具标题、状态标签及技术元数据设为 bold。这些互不协调
的规则与 Assistant 正文争夺注意力。彩色或加粗的路径、数量、耗时会显得与结论同样
重要。在较长的中英文混排回答中，频繁变化的字重尤其干扰连续阅读。

## 排版契约

| 角色 | 呈现规则 |
| --- | --- |
| 主阅读层 | Assistant 正文和用户文字使用 regular 与 V1A 的 primary/body 前景色。用户身份由消息表面区分，不靠整段加粗。 |
| 次阅读层 | 工具摘要、状态正文、引用和较低级标题使用克制的前景色与 regular 字重。 |
| 元数据 | 耗时、路径、ID、计数、提示及附带技术令牌使用 muted 或 secondary 的 regular 文字。技术令牌本身不等于强调。 |
| 语义状态 | 错误、警告、成功与焦点沿用 V1A 的语义色和边界；描述状态的整句话不因此变为 bold。 |
| 显式强调 | Markdown `strong` 与文档首级标题可使用 bold。焦点由现有选中/反色或边界表达，不依赖普遍加粗。 |

Markdown H1 是唯一加粗的标题，并保持左侧阅读轴。H2 使用 primary regular；H3 及更低级标题
按现有中性色文字角色逐级退让。正文、段落、列表及引用正文保持 regular；列表标记
与分隔线退到背景。引用不再把整段中文斜体化。行内代码只用克制的前景色，**绝不**
恢复填充背景的标签效果。围栏代码和 diff 保留独立表面；语法色只在代码中使用，
不把普通语法令牌普遍加粗。这是阅读角色层级，不是新调色板或字号体系。

Graphite、Porcelain、System 及其他主题共享相同的字重和语义角色决策；切换主题
只将角色解析到不同 palette。System 保留自适应表面与终端原生焦点回退。本决策不修改
Composer 尺寸或行为、对话宽度、间距、Header/Footer 结构、Runtime、Context 或
Session 行为。

## 验证

V0/V1A 的确定性 Textual 快照继续作为视觉契约。V1B 显式更新受影响快照，新增
中英文混排长回答 fixture。排版测试检查 Graphite、Porcelain、System 的最终语义样式，
包括行内代码无背景。并排 gallery 将已提交的 V1A 快照与 V1B 的长 Markdown、
用户/助手、工具活动、错误及中英文混排阅读场景比较。快照证明可复现性；System 的
实际 ANSI palette 与长文阅读体验仍需真实终端检查。
